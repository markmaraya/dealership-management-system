# 🚛 Dealership Management System

A full-stack **Dealership Management System** built with the **MEAN stack (MongoDB, Express.js, Angular, Node.js)**.  
This application streamlines dealership operations, including inventory management, sales monitoring, and expenses tracking.

---

## ✨ Features
- **Inventory Management**: Add, update, and track available vehicles.
- **Sales Monitoring**: Record transactions and monitor sold units.
- **Expenses Tracking**: Log and categorize operational costs and analyze spending patterns to optimize dealership finances.
- **RESTful API**: Node.js + Express backend with MongoDB integration.

---

## 🛠️ Tech Stack
- **MongoDB** – NoSQL database for storing dealership data
- **Express.js** – Backend framework for APIs
- **Angular** – Frontend framework for building dynamic UI
- **Node.js** – Runtime environment for server-side logic
- **Angular Material** – Modern UI components for Angular
- **SCSS** – Powerful styling with variables, nesting, and modular design
